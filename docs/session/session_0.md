## 🎯 Цель сессии
Подготовить все спрайтовые ассеты для игры, чтобы в первой игровой сессии уже работать со спрайтами (не примитивами).

---

## ✅ Результат после сессии
Папка `game/sprites/` содержит готовые PNG-спрайты:
- `spaceship.png` — треугольный корабль игрока
- `enemy_simple.png` — простой красный враг (круг)
- `enemy_fast.png` — быстрый синий враг (маленький круг)
- `enemy_boss.png` — босс (большой красный круг с глазом в центре)
- `bullet.png` — пуля (жёлтая полоса)
- `explosion.png` — эффект взрыва (круг с частицами)

---

## 🛠 Задачи

### 1. Создать папку для спрайтов (~2 мин)
```bash
mkdir -p game/sprites
```

### 2. Нарисовать и сохранить спрайты (~15 мин)

| Спрайт | Размеры (px) | Описание |
|--------|-------------|----------|
| `spaceship.png` | 48×64 | Треугольный корабль, зелёный |
| `enemy_simple.png` | 32×32 | Красный круг с двумя чёрными точками-глазами |
| `enemy_fast.png` | 20×20 | Синий маленький круг |
| `enemy_boss.png` | 76×76 | Большой красный круг, в центре — один большой глаз |
| `bullet.png` | 48×16 | Жёлтая полоса с заострённым носом |
| `explosion.png` | 32×32 | Белый/оранжевый круг с лучами (частицы) |

> **Совет:** Можно нарисовать в Paint, Krita или Figma, а затем сохранить как PNG. Или сгенерировать программно через Python + PIL, если нет графического редактора.

### 3. Проверка (~2 мин)
Открыть все спрайты в любом просмотрщике изображений и убедиться:
- Все файлы существуют
- Размеры соответствуют спецификации
- Контент соответствует описанию
